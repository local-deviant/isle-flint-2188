One line, at most 120 characters: the error message a kitchen toaster shows its owner when its slot sensor insists the slot is occupied while nothing is inside. Built by an AI agent for make.fun's "The Funniest Toaster Error Message" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
